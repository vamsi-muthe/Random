5.3 Why KB Struggles with Code (Industry Consensus)

Fundamental limitation: All three major vendors (AWS, Microsoft, Google) now acknowledge that dense embeddings trained on natural language underperform on code. Code meaning derives from AST structure, import hierarchies, and type systems - not text similarity. (Ref: Azure AI Search Agentic Retrieval announcement, May 2026; AWS Bedrock Agentic Retrieval blog, July 2026)

KB Failure Modes on Code:

  • Chunk boundary splits: A 300-token chunk cuts a function in half. The embedding captures half a function's semantics.
  • Cross-file blindness: "This module imports SecurityGroupRules from ../shared/" - KB cannot follow that import.
  • Identifier mismatch: Searching "IAM role for S3" semantically matches documentation ABOUT IAM, not the actual aws_iam_role resource block.
  • Hierarchy loss: A Terraform module's variables.tf defines the interface; main.tf implements it. KB returns one chunk from one file.

Why Agentic Excels on Code:

  • Exact match search: grep "aws_iam_role" finds every IAM role resource regardless of semantic distance.
  • Cross-file tracing: Agent reads an import, follows it to the source file, reads that too. Builds coherent multi-file context.
  • AST-aware: Can search for specific resource types, function signatures, or variable references.
  • Self-correcting: If first search yields nothing, agent reformulates and tries again (multi-hop reasoning).

5.4 Real Example: SIA Claim Verification

SIA Claim: "The Lambda function uses a CMK for environment variable encryption"

KB approach:
  - Embeds query -> finds chunks about Lambda encryption (docs, not code)
  - Returns: general Lambda best-practices text, maybe a random main.tf chunk
  - Synthesis LLM: "Cannot verify - no relevant code found" (false negative)

Agentic approach:
  - grep("aws_lambda_function", "terraform/") -> finds the resource
  - read_file(resource block) -> sees kms_key_arn is empty
  - grep("aws_kms_key", "terraform/") -> finds no KMS key resource
  - Conclusion: "Claim CONTRADICTED - no KMS key provisioned" (correct finding)
