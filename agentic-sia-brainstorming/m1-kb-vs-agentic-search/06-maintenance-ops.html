6. Maintenance & Operational Burden

With a 2-person part-time team, maintenance burden is a hard constraint, not a soft preference. KB requires 16-24 hrs/month; Agentic requires 2-8 hrs/month.

Why this matters: Our team is 2 engineers working on this part-time. Every hour spent debugging OpenSearch cluster health or fixing ingestion pipelines is an hour NOT spent improving the pipeline's actual security analysis quality. The maintenance cost isn't just dollars - it's opportunity cost against a constrained team.

6.3 Failure Mode Comparison

FailureKB Blast RadiusAgentic Blast Radius
Infrastructure downALL reviews blocked until OpenSearch recoversPer-query retry; fallback model available
Stale dataSILENT - all reviews use outdated code, no alertImpossible - reads live files
Model API errorN/A (no model in retrieval path)Single SIA fails; retries automatically
Cost spikeFixed (no spike possible)Bounded per-SIA; visible in billing immediately
Vendor deprecationRe-index ALL data (weeks of engineering)Change one config variable
The silent stale data risk is the most dangerous KB failure mode. If the S3 sync Lambda breaks silently, the pipeline validates SIA claims against code that is days/weeks old. For security review, this is worse than returning no result - it returns a confident wrong answer.
