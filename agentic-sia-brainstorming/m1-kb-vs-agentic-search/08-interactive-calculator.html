Code Retrieval Only - SIA Pipeline M1 Decision Support

Scope note: This calculator covers code retrieval costs only (the GTA agent's search path). It does NOT include costs for other pipeline agents (Entity Extraction, Synthesis, Compliance, HSA) which use Bedrock Converse regardless of retrieval approach. Those costs are additive and identical in both scenarios. Docs retrieval is also excluded - it stays on KB / ai-sre team's shared KB either way.
Agentic call calibration: Tool-call estimates are calibrated against real repos: cloud-scripts (506 files, 63K lines), agentic-sia (141 files, 26K lines), data-layer (1544 files, 340K lines). Per entity, the agent needs: 1 tree/discover call, 1-2 grep/search calls, 3-5 file reads (avg 150 lines = 600 tokens each), 1-2 import-follow calls. Total: 6-10 tool calls per entity with growing context window. The current GTA does 2-4 KB retrieves + 1 LLM query reformulation per entity for comparison.

What This Calculator Does NOT Include

Excluded (Same in Both Approaches)
  • Entity Extraction Agent - Sonnet 4 Converse call (~$0.15/SIA)
  • Synthesis Agent - Opus 4 Converse call (~$1.50/SIA)
  • Compliance Agent - OPA eval (no LLM cost)
  • Prose Compliance Agent - Sonnet 4 Converse call (~$0.30/SIA)
  • Historical SIA Agent - KB retrieve + rerank (~$0.05/SIA)
  • Docs retrieval - stays on KB either way
  • DynamoDB - state storage (~$5/month at all scales)
  • API Gateway + Lambda - compute (~$2/month)

Estimated additive cost: ~$2.00/SIA regardless of code retrieval approach.

Agentic Search Costs NOT Modeled
  • Code index infrastructure - grep/AST search needs an index. If using GitLab search API: free. If self-hosted (Zoekt, Sourcegraph): ~$50-200/month.
  • Rate limiting / throttling - Bedrock has per-model TPM limits. At burst (200 SIAs), concurrent calls may queue.
  • Cache layer - if same entities are searched repeatedly, a semantic cache saves ~30-50% of calls. Not modeled.
  • Retry cost - model timeouts/rate-limits cause retries. Add ~10-20% to agentic cost for production.
  • Quality iteration - prompt engineering time for the agentic search agent (~1-2 days setup, then minimal).
