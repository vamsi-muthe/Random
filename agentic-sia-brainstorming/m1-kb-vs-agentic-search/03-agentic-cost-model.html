3. Agentic Search Cost Model

How an LLM-driven tool-use agent searches code, and what it costs per SIA review across 7 foundation models.

Why this matters: Agentic search has ZERO fixed infrastructure cost. You pay only when a review runs. This section quantifies the per-query cost precisely so we can compare against KB's flat $700+/month floor. The key insight: even the most expensive model (Opus 4 at $13.50/SIA) is cheaper than KB at M0-M1 volumes because KB charges whether you use it or not.

3.1 How Agentic Code Search Works

The agent receives a query ("verify this SIA entity's claim about IAM roles"), decomposes it, and calls tools against live code:

Entity: "Database uses private subnet with no public IP"

Agent reasoning loop:
  Call 1: list_directory("terraform/modules/rds/")          -> sees main.tf, variables.tf
  Call 2: grep("publicly_accessible", "terraform/")        -> finds terraform/modules/rds/main.tf:47
  Call 3: read_file("terraform/modules/rds/main.tf", 40-60)-> reads the resource block
  Call 4: grep("subnet", "terraform/modules/rds/")         -> finds subnet_group reference
  Call 5: read_file("terraform/modules/vpc/subnets.tf")    -> confirms private subnet CIDR
  Call 6: grep("igw\|nat", "terraform/modules/vpc/")       -> verifies no IGW route
  Call 7: synthesize finding                               -> "Claim VERIFIED: RDS in private subnet"
Calibration source: Tool-call estimates derived from real repos: cloud-scripts (506 files, 63K lines, avg 102 lines/sh), agentic-sia (141 files, 26K lines, avg 212 lines/py), data-layer (1544 files, 340K lines). Pattern: 1 discover + 1-2 search + 3-5 file reads + 1-2 import follows = 6-10 calls typical.

3.2 Token Math (Context Window Growth)

Each tool call returns results that accumulate in the context window. This is the primary cost driver.

Per Entity (7 tool calls, calibrated estimate):
  Call 1:  2K input +  1K output =   3K tokens  (initial prompt + tool defs)
  Call 2:  6K input +  1K output =   7K tokens  (prior result in context)
  Call 3: 10K input +  1K output =  11K tokens
  Call 4: 14K input +  1K output =  15K tokens
  Call 5: 18K input +  1K output =  19K tokens
  Call 6: 22K input +  1K output =  23K tokens
  Call 7: 26K input +  1K output =  27K tokens
  ──────────────────────────────────────────────
  Total per entity: 98K input + 7K output = 105K tokens

Per SIA (12 entities): 1,176K input + 84K output = 1,260K tokens
Per SIA (15 entities): 1,470K input + 105K output = 1,575K tokens

3.3 Prompt Caching Impact (90% Discount)

Game-changer: Anthropic's prompt caching charges 0.10x (90% off) for cached prefix reads. The system prompt + tool definitions (~4K tokens) are identical across ALL 84 API calls in a single SIA. Cross-entity, prior results accumulate as a stable prefix. This cuts effective cost by 50-67%.
