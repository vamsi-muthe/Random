Executive Summary & Final Recommendation

Recommendation: Use Agentic Search (Sonnet 4 + Prompt Caching) for M0-M2. Re-evaluate KB at M3 scale ONLY if latency SLAs demand sub-2s retrieval.

The One-Paragraph Case

The OpenSearch Serverless minimum floor of $691/month (4 OCU always-on) creates an insurmountable cost disadvantage at low-to-medium volumes. Even at M2 scale (50 SIAs/month), Agentic Search with Sonnet 4 costs $45/month (with prompt caching) vs KB's $2,083/month - a 46x difference. The break-even point where KB becomes cheaper is approximately 718 SIAs/month - 7x beyond the most aggressive enterprise projection. Agentic search also offers superior freshness (real-time code access), better cross-file coherence (can follow imports), and zero maintenance overhead.

Scope Clarification

This analysis covers CODE retrieval only (the GTA agent's search path). It does NOT include costs for: Entity Extraction (~$0.15/SIA), Synthesis (~$1.50/SIA), Compliance (free, OPA), Prose Compliance (~$0.30/SIA), Historical SIA (~$0.05/SIA). Those costs are additive (~$2.00/SIA) and identical regardless of code retrieval approach. Docs retrieval stays on KB either way.
